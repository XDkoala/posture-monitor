# Posture Monitor

一个本地运行、浏览器端的低打扰实时坐姿提醒器。它会先记录用户舒服的自然中立位，再根据持续且明显的相对偏离提供提醒。

界面支持中文和英文即时切换，语言选择会保存在当前浏览器中；主页面、设置、校准、后台小窗和桌面通知会保持一致语言。

## 如何运行

需要 Node.js 20.19+（推荐 Node.js 22 或 24）。

```bash
npm install
npm run dev
```

打开终端中显示的本地地址。摄像头 API 要求安全上下文；`localhost` / `127.0.0.1` 可直接使用。

生产构建：

```bash
npm run build
npm run preview
```

类型检查：

```bash
npm test
```

## 浏览器支持

- Windows 上最新版 Chrome（优先）
- Windows 上最新版 Edge（优先）
- 其他支持 WebAssembly、MediaDevices、Canvas 和 ES2022 的现代桌面浏览器可能可用，但未列为主要测试目标

首次启动会从当前网站下载 MediaPipe Pose Landmarker 的 WASM 与轻量模型；这些运行资源随网站一起发布，推理不会把摄像头帧发送给服务器。

## 使用方法

1. 将摄像头放在正前方，保证完整头部、左右肩膀和部分上半身可见。
2. 启动摄像头并授权访问。
3. 点击“开始校准”，以自然、可正常呼吸的姿势保持约 4 秒。
4. 正常工作即可。短暂低头和活动不会立即触发提醒。
5. 更换椅子、桌面或摄像头位置后，用按钮或 `Ctrl + Shift + C` 重新校准。

### 浏览器后台监测

在 Chrome/Edge 桌面版中，启动监测后点击“开启后台小窗”。应用会打开一个始终置顶的精简状态窗：

- 主页面在前台时约以 15 FPS 分析。
- 后台小窗开启时约以 10 FPS 分析。小窗采用紧凑状态胶囊设计，暂停和桌面通知授权统一在主页面操作。
- 未开启小窗而页面进入后台时，应用改用定时器以约 2 FPS 尝试继续分析。
- 超过 5 秒没有完成一次推理时，页面和小窗会显示“后台监测受限”。

为了在切换应用或最小化主窗口后收到提醒，请开启桌面通知，并保留置顶后台小窗。纯后台标签页仍受浏览器和操作系统调度策略影响，无法提供与原生桌面程序相同的绝对保证。不支持 Document Picture-in-Picture 的浏览器会自动退化到低频后台定时器模式。

调试画面默认隐藏；打开后会显示关键点、肩线、躯干中轴、FPS、置信度、原始指标、状态机、异常持续时间和冷却时间。

视觉提醒在持续异常达到提醒时间后锁存显示，不需要用户确认或关闭。只要姿势仍为“需调整”，主页面红色边缘和置顶小窗的暖红色呼吸提示就会持续；姿势连续处于“良好”或“轻微偏离”500ms 后自动解除。识别丢失、暂停、停止或重新校准时会立即解除视觉提醒。系统启用“减少动态效果”时使用静态高对比边框。

## 隐私声明

- 摄像头数据仅在当前浏览器本地实时处理。
- 不上传视频帧、截图或姿态数据。
- 不录像、不截图、不保存面部图像。
- 不需要账户或云端数据库。
- 本地仅保存设置、校准后的数值参数、状态时间统计和提醒次数，最近保留 7 天。
- MediaPipe 运行时和模型资源随网站一起发布，不依赖第三方 CDN；应用不会主动上传摄像头帧、姿态结果或本地数据。

## 产品边界

> 本软件不是医疗设备，不能用于诊断颈椎疾病、脊柱侧弯、圆肩或其他肌肉骨骼疾病。

分数是来自正面单目摄像头的相对代理指标，不是厘米、角度或医学测量。提醒目标是回到舒服的自然中立位，而不是维持僵硬的所谓“标准姿势”。

## 实现概览

- Vite + TypeScript，无大型 UI 框架
- MediaPipe Tasks Vision Pose Landmarker（640×480、约 15 FPS）
- 4 秒多帧校准，使用 MAD 去异常值后的中位数
- 肩宽/躯干尺度归一化、多代理塌陷与头颈分数、EMA 时间滤波
- `GOOD → MILD → BAD_PENDING → REMINDER → COOLDOWN` 状态机
- 7 个上半身关键点位移的肩宽归一化中位数活动检测；连续帧确认，避免呼吸、打字和单点抖动误触发
- 置信度不足、离席和真正的大幅活动时暂停判定；调度切换或长帧间隔会重置活动比较
- 前台 `requestAnimationFrame`、后台定时器和 Document Picture-in-Picture 三路自适应调度
- Notification API、Web Audio 柔和提示音、非阻塞页面提醒
- LocalStorage 保存设置、基准和最近 7 天聚合统计；绝不保存原始帧

## 人工验收建议

PRD 中的 5 分钟正常坐姿与真实动作场景需要在实际摄像头前人工验证。可临时把提醒延迟设为 5 秒快速检查持续时间和冷却，再恢复默认 10 秒。打开“调试画面”观察分数与状态机，必要时集中调整 `src/config.ts` 中的阈值。
